# Air-Quality Pollutant Estimation

Compare an **LSTM**, a **Neural ODE** and a **PINN** that map low-cost sensor signals and meteorology
(temperature, relative & absolute humidity) to reference-analyzer **CO, NOx and NO₂** concentrations
(UCI Air Quality dataset, chronological 90/10 split).

Source code, training scripts and notebooks: https://github.com/isha-m63/04_Deep_Learning_Based_Pollutant_Forecasting
